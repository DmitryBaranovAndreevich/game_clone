# Сценарий игры

Игрок управляет космическим кораблем, который может передвигаться в пространстве, а так же стрелять.
Цель игры набрать как можно больше очков, cтреляя по врагам. Игра бесконечная с постепенно повышающейся сложностью.
Игра заканчивается, когда космический корабль сталкивается с врагом.

Управление:

|               Клавиша               | Описание                                                                                                                                                |
| :------------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ← | Движение влево                            |
| → | Движение вправо                            |
| ↑ | Движение вверх                            |
| ↓ | Движение вниз                            |
| Пробел | Стрельба                            |

_Хотелки:_

* Добавить разных врагов.
* Добавить уровни сложности.
* Добавить бонусы и бонусные уровни.
* Адаптация для мобильных устройств.

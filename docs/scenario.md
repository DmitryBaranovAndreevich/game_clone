# Сценарий игры

Игрок управляет космическим кораблем, который может передвигаться в пространстве, а так же стрелять.
Цель игры набрать как можно больше очков, cтреляя по врагам - печенькам. Каждая печенька имеет от 1 до 3 жизней. Когда игрок набирает определенное количество очков, он переходит на следующий уровень
Игра заканчивается, когда космический корабль сталкивается с врагом.

Управление:

|               Клавиша               | Описание                                                                                                                                                |
| :------------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ← | Движение влево                            |
| → | Движение вправо                            |
| ↑ | Движение вверх                            |
| ↓ | Движение вниз                            |
| Пробел | Стрельба                            |
